# Contributing

Every contribution of benchmark data must provide:

1. original source and bibliographic reference;
2. original instance identifier;
3. acquisition URL or archival source;
4. SHA-256 of the upstream file;
5. licence / redistribution status;
6. conversion rule or importer version;
7. validation status;
8. provenance for every known objective value or complete solution.

Never submit guessed data, inferred BKV values or silently corrected source files.
Corrections must be explicit and reproducible.
