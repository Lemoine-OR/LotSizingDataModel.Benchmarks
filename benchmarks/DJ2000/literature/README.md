# DJ literature reconciliation

The values in this directory are evidence records, not automatically trusted BKV.

The detailed 2011 medium/large tables are historical. A 2014 VNS/ADTS paper reports later improvements
for 5/40 medium and 30/40 large instances. No literature value is promoted until exact identity and
objective-convention equivalence are established. Complete solutions, when available, must pass
LotSizingDataModel.Checker.
