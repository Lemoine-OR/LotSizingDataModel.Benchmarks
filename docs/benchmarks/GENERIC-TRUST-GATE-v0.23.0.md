# Generic Trust Gate v0.23.0

This roadmap M2 release separates candidate validation from scientific promotion. A complete solution may become CHECKER_VERIFIED_FEASIBLE only after the full canonical Checker succeeds. The gate never edits the global trust catalogue, never promotes optimality, preserves timestamped reports, writes a checksumed decision record, and records rejected candidates without replacing prior evidence.

Optimality requires a separate, reviewable lower bound or proof matching the checked objective. Literature values without complete solutions must enter the evidence workflow, not this gate.
