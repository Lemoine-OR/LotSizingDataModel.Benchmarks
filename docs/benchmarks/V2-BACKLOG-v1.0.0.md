# Deferred work for v2.0

Version 1.0.0 closes the current corpus without changing LotSizingDataModel. The 27 deferred workstreams are recorded machine-readably in `V2-DEFERRED-WORK-v1.0.0.csv` and described in the accompanying Word backlog.

The main technical decision is support for shared production-family setups required by MULTILSB. The 120 normalized instances remain outside the canonical registry until an extension is specified, approved, implemented with backward compatibility, and validated by round-trip and Checker tests.

Other workstreams cover historical source acquisition, exact lineage checks, complete solutions, optimality evidence, and family-level licence/provenance documentation.
