# Release policy

Semantic versioning is used for the curated dataset.

- PATCH: documentation, metadata or non-semantic correction;
- MINOR: new benchmark families / instances / improved BKV;
- MAJOR: incompatible schema or identity-policy change.

Every release should publish:
- instance counts;
- family counts;
- BKV coverage;
- complete-solution coverage;
- verified-optimum coverage;
- list of changed reference values.
