# Tempelmeier ecosystem - source map

## Tempelmeier-Derstroff (1996)
Management Science 42(5), 738-757. DOI 10.1287/mnsc.42.5.738.
The original stable public archive is not yet confirmed. No original file is reconstructed silently.

## Stadtler (2003) MLCLSP
The public Suerie benchmark site provides the complete MLCLSP test set with objective values and lower bounds.
Sets: A+, B+, C, C+, D, D+, E, E+.
Archive: https://www.suerie.de/testsets/hst/ti_mlclsp.zip

## Suerie-Stadtler (2003) CLSPL
Three sets:
- data: converted Trigeiro-Thomas-McClain instances;
- datam: aggregated Phase III TTM instances;
- datab: 60 instances from Stadtler class B+.
Archive: https://www.suerie.de/testsets/clspl/testdata.tar.bz2

## Tempelmeier-Buschkuhl / Sahling et al.
1,920 MLCLSP-L instances in six classes:
C1 10x4x3 (480), C2 10x8x3 (480), C3 20x8x6 (240),
C4 20x16x6 (240), C5 40x8x6 (240), C6 40x16x6 (240).
Historical archive URL: http://www.scmp.uni-koeln.de/publikationen/ORS2008MLCLSPL.zip
