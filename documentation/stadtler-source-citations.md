# Source evidence

Primary source: Hartmut Stadtler and Christopher Suerie, *Description of MLCLSP Test Instances*,
TU Darmstadt, state December 20, 2000.

Evidence used:
- eight official test sets and their T/J/M/setup-time dimensions;
- seven-position nomenclature;
- official `start_ini.bat` generation mechanism;
- complete twelve-file generated instance contract;
- best-known solutions are not all proven optimal;
- some C/D/E instances match Tempelmeier-Derstroff exactly;
- CLSPL `datab` is a 60-instance subset of Stadtler B+.
