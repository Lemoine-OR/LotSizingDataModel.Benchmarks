The user-provided `E1.zip` contains exactly 751 logical Trigeiro instance identities, each represented
twice:

- 751 `.dat` files;
- 751 `.trig` files.

The family distribution is:

- E: 58
- F: 70
- G: 71
- W: 12
- X: 540

Total: 751 identities / 1502 source files.

## Dual-format reconciliation

The importer parses DAT and TRIG independently.

A pair is accepted only when both formats agree on:

- item count;
- period count;
- demand matrix;
- stationary machine capacity;
- unit production time;
- holding cost;
- setup cost.

The supplied DAT corpus contains zero for every `C_t_l_Produit*` setup-time field, whereas the TRIG
files contain the historical positive setup times. This affects all 12,306 DAT item setup-time
entries observed in the archive. v0.10.0 therefore records this as
`DUAL_FORMAT_RECONCILED_DAT_SETUP_TIME_LOSS` and takes the TRIG setup time as canonical only when all
shared fields agree.

Any other mismatch rejects the pair.

## Canonical model

The canonical instance is single-level, multi-item, single-machine, capacitated CLSP with setup
times. The source identifier is preserved (`E1`, `F...`, `G...`, `W...`, `X...`), and the current
LotSizingDataModel scientific classification/notation is generated by `LotSizingInstanceFactory`.
