# v0.11.0 — Trigeiro Authoritative TRIG Consolidation

Scientific provenance rule:

- `.trig` = `ORIGINAL_SOURCE / AUTHORITATIVE`;
- `.dat` = `DERIVED_SECONDARY_FORMAT / VALIDATION_ONLY`.

The 751 canonical LotSizingDataModel XML are rebuilt exclusively from the original TRIG files.

The DAT representation is parsed only to validate fields shared with TRIG. A DAT disagreement never
overrides an original TRIG value.

Derived validation statuses include:

- `DERIVED_DAT_VALIDATED`
- `DERIVED_DAT_KNOWN_SETUP_TIME_LOSS`
- `DERIVED_DAT_SETUP_TIME_MISMATCH`
- `DERIVED_DAT_OTHER_MISMATCH`
- `DERIVED_DAT_PARSE_FAILURE`
- `DERIVED_DAT_MISSING`

In the user-provided E1.zip, all 12,306 DAT setup-time fields and all 12,306 DAT production-cost
fields are zero. Setup times are present in the original TRIG and are therefore canonical. DAT-only
production costs are ignored because the original TRIG contract has no production-cost field.

The pack compares v0.10.0 and v0.11.0 by SupplyChainFingerprint before publishing the authoritative
corpus, then runs the structural Checker over all 751 instances.
