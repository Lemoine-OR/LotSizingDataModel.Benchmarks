# v0.12.0 — Trigeiro Results, BKV & Trust Gate

This release operates on the authoritative 751-instance TRIG corpus established in v0.11.0.

It introduces a conservative result trust catalogue. Literature values are never promoted to
`VERIFIED_FEASIBLE` or `VERIFIED_PROVEN_OPTIMAL` unless a complete solution certificate is available
and passes LotSizingDataModel.Checker.

## Seeded standard instances

The CLSP literature identifies the following standard Trigeiro G-series cases:

- G62 = tr6-30: objective 61746, literature lower bound 60946;
- G53 = tr12-15: objective 74634, lower bound 73848;
- G69 = tr12-30: objective 130596, lower bound 130177;
- G57 = tr24-15: objective 136509, lower bound 136366;
- G72 = tr24-30: objective 287929, lower bound 287753.

These are recorded as `LITERATURE_VALUE` with a literature optimality claim, not as repository-verified
solutions.

## G30 identity warning

Original G30 contains fractional unit production times. Later benchmark papers also use G30b, a
transformed unit-production-time variant. The frequently reported optimum 37721 therefore is not
attached to authoritative G30 without an exact identity/fingerprint proof.
