# v0.15.0 - Cattrysse Result Semantics & BKV Reconciliation

This release decodes the internal semantics of the three historical BIFF5 result workbooks.

Every TEST identity occurs exactly three times in its workbook:

1. objective/result values by method;
2. `afwijking` relative deviations;
3. `tijd` / `tijden` reported computation times.

For every deviation cell that is present, v0.15.0 requires the identity:

`deviation = method objective / workbook reference - 1`.

The hidden workbook reference cell is column 26. BIFF5 formula-level audit and value-level verification
show that it is the minimum over an explicit reference method set.

For `lot50.xls` and `lot20b.xls`:

`LV; DS; ABCX; ABCX20; ABCXexp; SC; HEUR1; HEUR2; HEUR3; HEUR4`

For `lot8.xls`:

`LV; DS; ABCX; ABCX20; ABCXexp; HEUR2; OPL4`

All 120 reference values equal the corresponding minimum exactly.

The resulting status is `LITERATURE_BEST_REPORTED`, not `VERIFIED_FEASIBLE` or
`VERIFIED_PROVEN_OPTIMAL`, because no complete production plan certificate is available for Checker
validation.

Outputs include the 120-row best-reported catalogue, long-form objective values, verified deviations,
reported timings, method hit counts, and an updated per-instance trust catalogue.
