# v0.17.0 - Global Registry Quality & Trust Normalization

This release adds a conservative, evidence-tiered trust model over the validated v0.16.4 global registry. It does not rewrite canonical XML and does not infer feasibility or optimality from a reported objective value.

The seven normalized statuses are `NO_REFERENCE_KNOWN`, `LITERATURE_REFERENCE_UNVERIFIED`, `LITERATURE_BEST_REPORTED`, `REFERENCE_WITH_LOWER_BOUND`, `COMPLETE_SOLUTION_UNCHECKED`, `CHECKER_VERIFIED_FEASIBLE`, and `VERIFIED_PROVEN_OPTIMAL`.

Open challenges are emitted only when recorded evidence supplies a concrete next action. Merely having no known reference is an informational state, not an automatically generated challenge.

All v0.16.4 corpus invariants remain release gates: 7,888 canonical rows, exact family counts, 50 historical-ID collision groups covering 100 rows, unique global IDs, zero exact fingerprint clusters, zero lineage edges, and the G30/G30b non-identity guard.
