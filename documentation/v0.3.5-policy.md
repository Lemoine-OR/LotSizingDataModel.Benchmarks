# v0.3.5 policy

## Stadtler

`start_ini.bat` is never called with invented parameters.

The pack searches the official batch/cmd files located beside each `start_ini.bat`. Only explicit,
literal invocations found in those source scripts are executed, and execution happens in an isolated copy
under `raw/generated-v0.3.5`.

If the official archive contains no literal invocation list, the pack reports zero generated instances
instead of guessing the seven-parameter factorial design.

## CLSPL

`sol.xls`, `solm.xls` and `solb.xls` are read with NPOI.

A reference table is accepted only when a header row identifies:
- an instance/name/id column; and
- an objective/best/upper-bound column.

A lower bound is extracted only when a separate lower-bound column is identifiable.

If the workbook structure is not self-describing, a complete cell-level workbook audit is generated and
no semantic values are promoted.

Published values receive `LITERATURE_BEST_KNOWN` / `LITERATURE_LOWER_BOUND`. They are not marked verified
without a complete solution that passes LotSizingDataModel.Checker.
