# v0.3.8 — CLSPL datab content fingerprint crosswalk

This pack replaces filename heuristics for the raw-datab -> LSDM bridge with the native
`LotSizingInstanceFactory.ComputeSupplyChainFingerprint` function.

Workflow:
1. re-convert the official raw CLSPL files in an isolated staging directory;
2. retain only source directories belonging to `datab`;
3. compute the official supply-chain fingerprint of each staged XML;
4. compute the same fingerprint for the 1,291 canonical CLSPL XML files;
5. accept a raw -> canonical mapping only when the fingerprint is unique;
6. map `solb.xls` IDs to raw datab directory identities using exact leaf IDs or unique
   leaf-only numeric IDs;
7. promote only those mappings for which both bridges are unique.

No row-order mapping is used.
