# v0.3.9 — per-directory CLSPL datab fingerprint repair

v0.3.8 found the 60 raw `datab` directories but associated zero staged XML with them.
The weakness was the global reconversion/log-association step.

v0.3.9 eliminates that dependency.

For each of the 60 raw `datab` directories independently:

1. create an isolated output directory;
2. run the existing CLSPL converter on that single source directory;
3. require exactly one generated XML;
4. calculate the native `LotSizingInstanceFactory.ComputeSupplyChainFingerprint`;
5. match that fingerprint against all canonical CLSPL XML;
6. accept the raw -> canonical mapping only when unique.

The second bridge (`solb.xls` -> raw directory) still uses only exact leaf identity or
a unique numeric identity extracted from the leaf itself. Row order is never used.
