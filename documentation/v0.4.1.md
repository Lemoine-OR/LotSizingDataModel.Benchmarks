# v0.4.1 - incremental Stadtler post-processing

Validates the existing 2,100 canonical XML and 8/8 VALID checker reports, then performs only batch fingerprinting, literature remapping and GitHub documentation. It never executes start_ini.bat and never rewrites canonical XML.

## R1 fix

The directory-creation helper is named `Ensure-Directory`. `Dir` is not used because
Windows PowerShell 5.1 resolves the built-in `dir` alias as `Get-ChildItem`, which caused
the original incremental runner to fail before creating `reports\v0.4.1`.

## R2

Existing checker evidence is accepted through one of three non-destructive checks:
`SUMMARY_OVERALL_VALID`, `SUMMARY_COUNTS_VALID`, or `MANIFEST_NO_FAILURE_MARKERS`.
