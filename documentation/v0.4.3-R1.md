# v0.4.3 R1 — semantic literature reconciliation

The original v0.4.3 collected all CSV files produced by `StadtlerReferenceReader`.
Each workbook run produces three CSV files, so aggregating them blindly duplicated semantic
references. It yielded 1,964 rows instead of the expected 982.

R1 fixes this at the source.

For each reader run:
1. read every produced CSV;
2. normalize source IDs to the seven-position Stadtler code;
3. semantically deduplicate each CSV by `(test set, code, objective, lower bound)`;
4. compare each CSV set to the reader's `resolved=N` count;
5. select an exact set when available, otherwise use the semantic union only if its count is exactly N;
6. fail if the reader output cannot be reconciled exactly.

After all physical workbook copies are processed, rows are globally deduplicated by the same semantic
identity. The hard postcondition is exactly 982 rows with the documented distribution:

A+ 120; B+ 312; C 180; C+ 10; D 80; E 90; E+ 10; legacy classcm 180.

No row-order inference is used.
