# v0.4.3 R2 — schema-independent Stadtler literature reconciliation

R1 still assumed it knew the reader CSV column names. R2 removes that assumption.

For every CSV produced by `StadtlerReferenceReader`, R2:
- imports the table without assuming a schema;
- scans every cell for a valid seven-position Stadtler code;
- counts unique canonical codes;
- detects objective and lower-bound columns from header semantics when available;
- selects the CSV whose unique-code count exactly equals the reader's `resolved=N`;
- if several CSVs match, chooses the richest one (objective/lower-bound coverage);
- emits a complete schema audit if no CSV matches.

Across physical workbook copies, references are deduplicated by `(test set, canonical code)`.
If equally rich copies disagree on objective/lower bound, the pack fails rather than choosing silently.

Hard postconditions:
A+ 120; B+ 312; C 180; C+ 10; D 80; E 90; E+ 10; legacy classcm 180; total 982.
