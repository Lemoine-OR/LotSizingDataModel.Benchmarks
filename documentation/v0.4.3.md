# v0.4.3 — complete Stadtler literature reconciliation

This release is strictly incremental.

It preserves:
- 2,100 generated Stadtler XML;
- 1,281/1,281 CLSPL literature mappings;
- all existing Checker evidence.

It does not run the source generators, the XML converter or the Checker.

## Workbook reconciliation

All `solutions*.xls` paths are discovered from the materialized upstream archives and grouped by
SHA-256. Only one physical copy of each identical workbook is processed.

The existing `StadtlerReferenceReader` is executed in isolated staging directories. Its CSV outputs
are collected independently of their exact filenames and normalized into one canonical schema.

A hard postcondition requires **982 unique literature rows**, matching the previously observed
published workbook coverage:

- A+: 120
- B+: 312
- C: 180
- legacy classcm: 180
- C+: 10
- D: 80
- E: 90
- E+: 10

## Mapping

Official rows are mapped using:

`official test set + canonical seven-position Stadtler code`

No row-order mapping is allowed.

`solutionscm.xls` is kept as legacy/non-official evidence.

## Genealogy

The published 60-instance relation `Stadtler B+ -> SUERIE_CLSPL datab` is recorded independently
from exact LSDM fingerprint equality. A zero exact-fingerprint result does not contradict the
published genealogy because the two conversion paths reconstruct/represent source parameters
differently.
