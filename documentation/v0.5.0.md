# v0.5.0 — Tempelmeier-Derstroff 1996 and Stadtler closure

This pack begins the TD1996 benchmark family without fabricating unavailable historical data.

## Evidence known from the literature

Tempelmeier and Derstroff (1996) study the dynamic multi-level multi-item capacitated lot-sizing
problem with setup times. Later literature describes:
- Class A: 1,500 instances with 10 items, 4 periods and 3 resources, no setup times;
- Class B: 600 instances generated from Class A with setup times;
- a 600-instance group with 40 items, 16 periods and 6 resources;
- a 150-instance large group with 100 items, 16 periods and 10 resources.

The Stadtler benchmark documentation states that some Stadtler C, D and E instances with
corresponding attributes match Tempelmeier-Derstroff (1996) exactly.

## Conservative policy

The repository never relabels all Stadtler C/D/E XML as TD1996. It records a conservative
zero-seasonality candidate set and waits for original TD1996 identifiers or raw data to prove each
file-level crosswalk.

## Stadtler unresolved references

The 75 literature rows left by v0.4.3-R2 are classified using:
- unique official class + seven-position code;
- the v0.4.0 generator/materialization manifest;
- explicit rejection/out-of-domain status.

No line-order inference is used.

## Acquisition

The installer searches `D:\Dev`, `D:\temp`, Documents and Downloads for Tempelmeier/Derstroff/TD1996
files. Original instances are converted only after a dedicated format audit in the next execution stage.
Missing source data are not synthesized.
