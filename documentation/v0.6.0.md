# v0.6.0 — TD1996 Full Integration

This release performs a complete local-source audit and integrates every Tempelmeier-Derstroff
candidate that can be demonstrated to satisfy a known MLCLSP source contract.

It:
- preserves Stadtler 2100/2100 and CLSPL 1281/1281;
- audits every v0.5.0 candidate file;
- expands local ZIP archives;
- scans for directories containing `INDEX.PRN`;
- recognizes the explicit 12-file MLCLSP contract and the repaired datab/B+ contract;
- deduplicates source directories by a deterministic directory fingerprint;
- converts every recognized directory with the existing LotSizingDataModel converter;
- structurally checks all resulting canonical TD1996 XML;
- computes exact SupplyChainFingerprint crosswalks against Stadtler C/D/E;
- records group-level published results separately from instance-level BKV values.

Unknown contracts are never guessed. Group-average or group-best literature values are never
attached to individual XML files.

The original Tempelmeier-Derstroff paper is:
Horst Tempelmeier and Matthias Derstroff (1996),
A Lagrangean-Based Heuristic for Dynamic Multilevel Multiitem Constrained Lotsizing with Setup Times,
Management Science 42(5):738-757, DOI 10.1287/mnsc.42.5.738.

Later literature reports benchmark-group results and confirms use of the Tempelmeier-Derstroff
instances. The Stadtler benchmark documentation also states that some C/D/E instances with
corresponding attributes match TD1996 exactly.
