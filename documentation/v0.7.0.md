# v0.7.0 — TD1996 Contract Discovery & Full Import

v0.6.0 showed that filename-based TD1996 discovery produced false positives from the benchmark
repository's own historical packs. v0.7.0 changes the acquisition model completely.

## Source discovery

The pack searches for `INDEX.PRN` directories by content and excludes:
- STADTLER2003 canonical/raw trees;
- SUERIE_CLSPL canonical/raw trees;
- repository reports and tools.

Every candidate directory is audited by:
- complete filename signature;
- file count;
- file SHA-256 values;
- deterministic directory fingerprint;
- safe ASCII first records;
- initial integers extracted from `INDEX.PRN`.

## Contract groups

Directories are grouped by exact filename signature. Each group is compared to:
- the explicit 12-file MLCLSP source contract;
- the 16-file datab/B+ contract discovered and repaired in v0.3.10/v0.3.11.

Only recognized contracts are converted automatically. Unknown groups remain evidence for a future
specific parser; no format is guessed.

## Conversion

Recognized sources are converted with the existing LotSizingDataModel converter, byte-deduplicated,
promoted into TD1996 canonical XML and structurally checked.

## Stadtler unresolved references

The 75 remaining literature codes are classified separately. C/D/E references are marked only as
possible TD1996-related classes; they are never promoted without an identity proof.
