# v0.8.0 — Historical Benchmark Acquisition & TD1996 Recovery

This release changes TD1996 handling from local filename search to evidence-driven web acquisition.

## Tempelmeier-Derstroff 1996

A currently indexed public professor profile for Horst Tempelmeier explicitly lists a
`testdata.zip` download next to:

Tempelmeier, H. and M. Derstroff,
*A Lagrangean-based heuristic for dynamic multi-level multi-item constrained lotsizing with setup
times*, Management Science 42(5), 738-757.

The runner downloads the source HTML, discovers an actual `href` containing `testdata.zip`, resolves
the relative URL and downloads the file. It does not hard-code or guess the archive path.

If that living link is unavailable, the runner queries the Internet Archive CDX API for historical
`*.uni-koeln.de/*testdata.zip` captures and attempts actual archived URLs returned by the index.

Every successful download records:
- exact source page;
- exact artifact URL;
- UTC acquisition time;
- SHA-256;
- byte length.

The archive is expanded only if it is a valid ZIP. `INDEX.PRN` directories are classified against
the two MLCLSP contracts already demonstrated in this repository. Only recognized contracts are
converted and checked.

## Trigeiro 1989 fallback

If TD1996 cannot be recovered or contains no recognized contract, the same run acquires the public
GitHub repository `gsamaro/trigeiro_fdata`, which describes itself as the Trigeiro et al. (1989)
datasets.

v0.8.0 inventories `.dat`/`.txt` raw files with hash and safe previews. It does not guess the CLSP
format yet; this becomes the input for the next full Trigeiro importer if necessary.

## Invariants

Stadtler remains 2100/2100 and CLSPL remains 1281/1281. Missing historical data are never
synthesized, and group-level published results are never attached to individual instances without
an identity crosswalk.
